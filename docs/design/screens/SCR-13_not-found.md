**パス**: 上記に該当しないすべてのパス　**ログイン**: 不要　**関連要件**: 6.4

## 目的

存在しない URL を開いたときの受け皿。あわせて、存在しないユーザー・投稿（404）と想定外エラーの表示形式の基準を示す。

## ワイヤーフレーム

```
+--------------------------------+
| nocolor                    (o) |
+--------------------------------+
|                                |
|           ( ? )                |
|   ページが見つかりません       |
|                                |
|   URL が間違っているか、       |
|   ページが移動または削除された |
|   可能性があります。           |
|                                |
|     [ ホームへ戻る ]           |
+--------------------------------+
```

- 表示項目、文言、動作は 3.6.2 に従う。API は呼ばない。
- 想定外のエラー（エラーバウンダリ）の全画面表示も、この形式（アイコン、見出し、説明、ボタン）で作る。

## 使用する API

なし（API-01 によるヘッダーの表示のみ）
